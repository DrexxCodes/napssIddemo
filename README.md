# Student Digital ID (Presentation Mockup)

A frontend-only mockup of a university student digital ID page for my university cos why not.

## Run it

Save `index.html` and open it in a browser. An internet connection is needed for the Tailwind CDN, the Inter font, and the DiceBear avatar.

## What is inside

- Student profile header with a DiceBear avatar seeded by the registration number (2024134106), so it stays the same on every load
- Academic session row (2026/2027, 1st semester)
- Two accessible tabs (Attendance, School Fees) with arrow key, Home and End support
- Attendance ring showing exactly 88% (SVG with `pathLength="100"`)
- Course details with green Registered and red False carryover status
- School fees status and a three-row mock payment history table

## Stack

Semantic HTML5, Tailwind CSS (CDN), vanilla JavaScript.
